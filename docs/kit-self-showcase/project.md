# DemoPack · 一次演示，四份发布材料

DemoPack 面向网页项目维护者，把明确的演示步骤整理成四份同源发布材料。

## 解决什么问题

减少项目发布时分别录屏、剪短片、截图与整理介绍的重复工作。

## 如何使用

运行 init 创建本地示例，填写 demo.json 中的步骤和说明，然后运行 generate。完成后使用 preview 查看、verify 校验。

## 四份材料

详细视频保留全过程；短视频选择重点步骤；竖屏图文视频使用同次运行的截图；项目介绍使用作者填写的功能、用法与限制。

## 本地与边界

运行不需要账号或模型密钥，不导入用户浏览器身份，不上传。需要 Node.js、Chromium、FFmpeg 与 ffprobe；截图采样不适合高速运动分析，当前无配音或音乐。
