# 四份发布材料版本验收（2026-09-16）

结论：本地可评审。四份材料已进入正式生成链路，默认初始化即可使用；尚未发布仓库或 npm 包。

## 本轮实现

- 可选 release 配置：短片选段、竖屏卡片、项目介绍与发布文案。
- 默认中文入门示例直接生成详细视频、简短视频、竖屏图文视频与项目介绍。
- 真实步骤编号与时间区间贯穿导出；卡片引用的步骤自动截图；旧配置仍兼容。
- 四个入口的中文离线预览，保留 GIF、README 图文片段与完整步骤阅读页。
- 新产物纳入哈希、必需文件和来源关系校验；失败或取消只留下 failure.json。
- 中英文说明、配置文档、贡献说明、发布草稿、CI 与 npm 文件白名单同步更新。
- 没有新增运行依赖，继续使用原有 Playwright、Zod 与外部 FFmpeg；许可边界未变化。

## 尚未证明

- Windows 本机已验证；Linux CI 已加入新场景但未远程执行，macOS 未实测。
- 未验证平台当期上传审核、流量、Star、跨设备字体一致性或真实用户再次使用。
- 无配音、音乐、编辑器或云功能；项目介绍来自作者填写，不自动阅读或推断项目能力。
- 静态卡片与截图采样适合产品教程，不能代替高帧率动画录制。
- 用户仍需确认素材与介绍准确；文件哈希不是真实性证明或数字签名。

下一步最重要的产品验证：维护者能否独立写好步骤并导出，以及四份材料中哪些被实际采用、是否愿意在下次发布复用。
