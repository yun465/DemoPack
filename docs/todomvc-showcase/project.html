TodoMVC · 从任务清单到完成记录

TodoMVC 是 tastejs 在 GitHub 维护的待办应用示例集合，用同一类任务管理功能展示不同前端技术的实现。本次选用 JavaScript ES6 示例，由 DemoPack 在本地真实运行并导出材料。

项目是什么

项目地址：https://github.com/tastejs/todomvc 。本次使用 examples/javascript-es6，而不是整个仓库的所有框架实现。它适合学习前端交互、观察 MVC 结构，以及比较同类应用的实现方式。

这次实际演示了什么

依次输入三项虚构任务，使用 Enter 提交；完成第一项；检查剩余数量；切换待完成和已完成筛选；回到全部列表；清除已完成任务。每个动作均由真实 Chromium 执行。没有预先填入数据库，也没有用静态页面模拟结果。

如何跟着操作

在顶部输入任务后按回车。点击任务左侧圆圈标记完成。底部 All、Active、Completed 分别表示全部、待完成、已完成；Clear completed 用来清除完成项。目标项目的原始界面保持英文，演示字幕、包装和项目介绍为中文。

实现与运行方式

该示例使用原生 JavaScript ES6 和 MVC 结构，Webpack 负责构建。示例 README 说明使用内存数据保存待办。本次直接启动该提交已经跟踪的 dist 静态构建，没有额外安装它的构建依赖，也未修改它的页面或脚本。
