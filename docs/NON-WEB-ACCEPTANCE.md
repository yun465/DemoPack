# 非网页输入验收 · 2026-09-16

新增 `report` 和 `media` 两个正式 CLI 入口，没有新增运行依赖。
实现范围：把来源文件生成讲解页，真实浏览器回放后导出四份材料，同时保留原始字节及来源清单。
不执行用户配置中的命令，不连接串口、不烧录 ESP，不声称素材回放等于现场实测。

## 本轮验证

- 构建、类型检查、格式检查、18 项单元测试通过。
- 6 项导入集成场景通过：两入口真实 CLI 导出、移动中文路径后离线播放、来源篡改拒绝、
  视频区间超界拒绝、取消后只有 failure.json、损坏图片报错。
- 导入视频结束区间真实浏览器回归通过；原 `init → generate` 四份材料回归通过。
- 最终两份材料的三段 MP4 和 GIF 全文件解码通过；实测尺寸、时长、体积，并检查实际截图、
  抽帧、竖屏卡片与中文字幕。完整性校验分别覆盖 25 和 22 个文件。
- 最终包复制到中文与空格路径，375 / 1280 宽度离线打开；三段成品视频实际开始播放，图片解码、
  文章跳转及 README 图片引用通过。导入集成测试还验证来源页原始视频可离线播放、无外网请求。
- 最终平均采样率约 9.16 / 9.13 fps，最大间隔约 124 / 143 ms，两包无采样质量警告。

## 检查发现与修复

来源页的 SHA-256 在手机窄屏上撑宽页面，已增加换行并重测。
材料视频最初可能在设定区间结束后继续播放，已增加结束控制与专门的浏览器回归。
一次报告录制出现约 0.8 秒采样间隙，保留诊断记录后重新录制；交付包无该警告。

本机证据保存在忽略的 `test-results/`：
`imports-1789531058375/results.json`、`kit-1789531314890/results.json`、
`todomvc-review-1789531354067/results.json`、`todomvc-review-1789531361058/results.json`。
最后两项复用了通用材料验收脚本，其历史名称包含 todomvc，但此次检查对象是本页两份导入产物。

Windows / Chromium 已验证。本轮未进行真实 ESP 设备验收、macOS 实机验收或带音轨合成验证。
GitHub CI 状态请以对应提交的 Actions 结果为准；本报告不把旧版本 CI 通过当作新版本验证。
